Build a complete “Project Meetings” module inside Tazq.

IMPORTANT:
- First inspect the existing Tazq application, database schema, project module, users, teams, clients, client members, tasks, workspace, notifications, permissions, file handling and PDF generation.
- Reuse existing entities wherever possible.
- DO NOT create duplicate User, Client, Client Member, Project Member, Task, Workspace or Notification entities.
- Do not break any existing functionality.
- Follow the existing Tazq UI/design system.
- The module should feel like an enterprise project meeting management system, NOT simply a calendar page.

========================================================
1. PURPOSE
========================================================

Project Meetings is a project-level module where the Project Manager can:

- Create project meetings
- Schedule internal or client meetings
- Define meeting type
- Select attendees
- Create calendar invitations
- Integrate with external calendars
- Define agenda
- Record meeting minutes
- Record discussion items
- Record decisions
- Create action items
- Assign responsibility
- Set due dates
- Track action item status
- Link action items to Tazq Tasks where appropriate
- Generate professionally formatted Meeting Minutes PDF
- Maintain a complete meeting history for the project

The module should answer:

“What meetings have happened on this project, what was discussed, what was decided, and who needs to do what?”
